# MyYL Mini App — Young Life Україна

Telegram Mini App для команд Young Life: звіти (клуби, малі групи, контактна робота), знані по імені, склад команди, фінансовий звіт, календар і статистика за ролями.

- **Інтерфейс** — ця папка, викладається на GitHub Pages: `https://vovayounglife.github.io/MyYL-mini-app/`
- **Бекенд** — `backend/Code.gs`, Google Apps Script у таблиці «⚙️ Система» на Google Диску.
- **Дані** — лише на Google Диску: `Young Life Mini App / Регіон / Ерія / Команда «…»`. На GitHub — тільки код.

## Запуск (один раз)

### 1. GitHub Pages
Settings → Pages → **Source: Deploy from a branch** → Branch: **main**, папка **/ (root)** → Save.
За хвилину-дві сайт буде за адресою вище (поза Telegram він покаже «Відкрий через Telegram» — так і має бути).

### 2. Бот
У Telegram відкрий **@BotFather** → `/newbot` (або візьми токен наявного бота) → скопіюй токен.

### 3. Таблиця «⚙️ Система» і скрипт
1. На своєму Google Диску (краще особистий Gmail) створи нову Google Таблицю, назви її **⚙️ Система**.
2. **Розширення → Apps Script**. Видали все в `Code.gs` і встав вміст файлу [`backend/Code.gs`](backend/Code.gs). Збережи (💾).
3. Онови вкладку з таблицею — зʼявиться меню **🤖 Бот**.
4. **🤖 Бот → 1. Створити структуру** → дозволь доступ (Google попросить підтвердити; «Додатково → Перейти до проєкту»).
   Створяться аркуші, папка «Young Life Mini App» на Диску, регіон West Side з 6 еріями.
5. **🤖 Бот → 2. Вказати токен бота** → встав токен.

### 4. Розгортання
1. В Apps Script: **Розгорнути → Нове розгортання** → тип **Вебзастосунок**.
   - Виконувати як: **Я**
   - Хто має доступ: **Усі**
2. Скопіюй URL (закінчується на `/exec`).
3. У таблиці: **🤖 Бот → 3. Підключити бота** → встав URL.
4. Відкрий одноразове посилання з вікна у своєму Telegram — отримаєш найвищу роль **Раб Божий** (власник системи).

### 5. Адреса бекенду для інтерфейсу
Впиши URL `/exec` у [`config.js`](config.js) (`API_URL: '…'`) — або просто надішли його Claude, він закомітить.

### 6. Нагадування
**🤖 Бот → 🔔 Увімкнути нагадування**: звіти — у неділю о 18:00 (змінюється на аркуші «Налаштування»), події — щодня о 9:00 тим, хто записався.

Готово: напиши боту `/start` → «Відкрити Young Life». Поділись ботом з капітанами — вони реєструються, ти (або ерія) підтверджуєш.

## Після будь-якої зміни бекенду
Apps Script → **Розгорнути → Керувати розгортаннями → ✏️ → Версія: «Нова версія» → Розгорнути**. URL лишається той самий.
Зміни інтерфейсу (файли в цьому репозиторії) підхоплюються самі за 1–2 хвилини.

## Ролі (зверху вниз)
**Раб Божий** (власник, найвища роль) · Національний Адмін · Регіональний Директор · Регіональний Адмін · Еріа Директор · Еріа Адмін · Капітан · Адмін команди · DGL · Лідер · Помічник · Сахарок · Волонтер · Працівник офісу.

| Що | Хто |
|---|---|
| Клуби | вносять Капітан, Адмін команди (і вищі ролі — за будь-яку команду у своїх межах) |
| Малі групи | Лідер, DGL і вище |
| Контактна робота | Помічник і вище |
| Знані по імені | Помічник і вище в команді + ерія, регіон, нац. |
| Фінанси | Капітан, Адмін команди + ерія, регіон, нац. |
| Події в календар | Лідер і вище — у календар свого рівня (команда / ерія / регіон / Україна) |
| Підтвердження ролей | Раб Божий — будь-яку. Нац. Адмін, Рег. Директор — лише Раб Божий. Рег. Адмін і Еріа Директор — Рег. Директор свого регіону. Еріа Адмін — Еріа Директор або регіон. Капітан — Еріа Директор, Еріа Адмін або Рег. Адмін. Решту — Капітан і вище. Сповіщення отримують лише найближчі відповідальні |
| Працівник офісу | роль рівня регіону (Office); поки що бачить лише календар у межах офісу |
| Кілька ролей | одна людина може мати будь-яку кількість ролей; Раб Божий додає собі ролі без підтвердження |
| Раб Божий | найвищі права; видається лише посиланням з меню «👑 Посилання для власника» |
| Ерії (додати, перейменувати) | Раб Божий — усі регіони; Регіональний Директор / Адмін — свій регіон |
| Команди (створити, перейменувати, закрити) | Еріа Директор — своя ерія; регіон — свій регіон; Раб Божий — усюди |
| Сахарок | бачить лише склад команди, календар і статистику клубів |

Доступ до таблиць на Диску (лише читання) скрипт видає сам на Gmail: Капітан → таблиця команди, ерія → папка ерії, регіон → папка регіону, Нац. Адмін → уся папка. Зняли роль — доступ забирається.

## Безпека
- Кожен запит підписаний Telegram і перевіряється на сервері токеном бота — підробити чужий акаунт не можна.
- Таблицю «⚙️ Система» не давай редагувати нікому, крім адмінів: редактори бачать усі дані й код.
- Імена й контакти підлітків — лише за згодою батьків.
