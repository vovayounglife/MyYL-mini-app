# MyYL Mini App — Young Life Україна

Telegram Mini App для команд Young Life: звіти (клуби, малі групи, контактна робота), знані по імені, склад команди, фінансовий звіт, календар і статистика за ролями.

- **Інтерфейс** — ця папка, викладається на GitHub Pages: `https://vovayounglife.github.io/MyYL-mini-app/`
- **Сервер** — [`worker/`](worker/): Cloudflare Workers + база D1 (акаунт Cloudflare власника). Відповідає за 20–80 мс, нагадування шле сам щогодини.
- **Копія на Google Диску** — [`backend/DriveSync.gs`](backend/DriveSync.gs) у таблиці «⚙️ Система»: кожні 10 хв дописує нове в `Young Life Mini App / Регіон / Ерія / Команда «…»` і роздає доступи за ролями.
- На GitHub — тільки код. Токен бота й ключі — лише в секретах GitHub/Cloudflare.

## Як оновлюється
Будь-яка зміна в репозиторії викладається сама: інтерфейс — GitHub Pages (1–2 хв), сервер — GitHub Actions «Сервер (Cloudflare)» (2–3 хв, спершу проганяє тести). Вручну нічого вставляти не треба.

## Запуск сервера (один раз)

### 1. Cloudflare
1. Зареєструйся на dash.cloudflare.com → **Workers & Pages** → обери піддомен `*.workers.dev`.
2. Праворуч у Workers & Pages скопіюй **Account ID**.
3. **My Profile → API Tokens → Create Token → шаблон «Edit Cloudflare Workers» → Use template**. У «Permissions» додай рядок **Account · D1 · Edit** → Continue → Create Token → скопіюй токен.

### 2. Секрети в GitHub
Репозиторій → **Settings → Secrets and variables → Actions → New repository secret** — чотири штуки:

| Назва | Що вставити |
|---|---|
| `CLOUDFLARE_API_TOKEN` | токен з кроку 1.3 |
| `CLOUDFLARE_ACCOUNT_ID` | Account ID з кроку 1.2 |
| `BOT_TOKEN` | токен бота від @BotFather |
| `SYNC_KEY` | будь-який довгий випадковий рядок (30+ символів) — пароль між сервером і таблицею |

### 3. Перший запуск
**Actions → «Сервер (Cloudflare)» → Run workflow**. Через 2–3 хв у підсумку запуску буде **адреса сервера** (`https://yl-mini-app.….workers.dev`). Бот уже переключений на новий сервер.

### 4. Таблиця «⚙️ Система»
1. **Розширення → Apps Script** → у `Code.gs` видали все й встав вміст [`backend/DriveSync.gs`](backend/DriveSync.gs) → 💾. Онови вкладку таблиці — зʼявиться меню **☁️ Сервер**.
2. **☁️ Сервер → 1. Підключити до сервера** → адреса з кроку 3 і той самий `SYNC_KEY`.
3. **☁️ Сервер → 2. Перенести дані на сервер** — усе, що вже внесли, переїде в нову базу.
4. Інтерфейс переключається на нову адресу в [`config.js`](config.js) (`API_URL`).
5. **☁️ Сервер → 3. Увімкнути копіювання на Диск**.

Посилання для власника застосунку — **☁️ Сервер → 👑 Посилання для власника**. Час нагадування про звіти — аркуш «Налаштування» (переноситься кроком 4.3) або таблиця `settings` у D1.

## Ролі (зверху вниз)
**Власник** (повний доступ, у застосунку не показується) · Національний Адмін · Регіональний Директор · Регіональний Адмін · Еріа Директор · Еріа Адмін · Капітан · Адмін команди · DGL · Лідер · Помічник · Сахарок · Волонтер · Працівник офісу.

| Що | Хто |
|---|---|
| Клуби | вносять Капітан, Адмін команди (і вищі ролі — за будь-яку команду у своїх межах) |
| Малі групи | Лідер, DGL і вище |
| Контактна робота | Помічник і вище |
| Знані по імені | Помічник і вище в команді + ерія, регіон, нац. |
| Фінанси | Капітан, Адмін команди + ерія, регіон, нац. |
| Події в календар | Лідер і вище — у календар свого рівня (команда / ерія / регіон / Україна) |
| Підтвердження ролей | Власник — будь-яку. Нац. Адмін, Рег. Директор — лише власник. Рег. Адмін і Еріа Директор — Рег. Директор свого регіону. Еріа Адмін — Еріа Директор або регіон. Капітан — Еріа Директор, Еріа Адмін або Рег. Адмін. Решту — Капітан і вище. Сповіщення отримують лише найближчі відповідальні |
| Національний офіс | посада зі списку (Офіс / Експерти) або своя; підтверджують Національний Адмін і власник; поки що бачить лише календар |
| Кілька ролей | одна людина може мати будь-яку кількість ролей; власник додає собі ролі без підтвердження |
| власник | найвищі права; видається лише посиланням з меню «👑 Посилання для власника» |
| Ерії (додати, перейменувати) | власник — усі регіони; Регіональний Директор / Адмін — свій регіон |
| Команди (створити, перейменувати, закрити) | Еріа Директор — своя ерія; регіон — свій регіон; власник — усюди |
| Сахарок | бачить лише склад команди, календар і статистику клубів |

Доступ до таблиць на Диску (лише читання) скрипт копіювання видає сам на Gmail: Капітан → таблиця команди, ерія → папка ерії, регіон → папка регіону, Нац. Адмін → уся папка. Зняли роль — доступ забирається.

## Безпека
- Кожен запит підписаний Telegram і перевіряється на сервері токеном бота — підробити чужий акаунт не можна.
- Таблицю «⚙️ Система» і акаунт Cloudflare не давай нікому, крім адмінів: там усі дані.
- Службові адреси сервера (`/admin/…`) працюють лише з ключем `SYNC_KEY`; вебхук бота — лише з секретом, який знає Telegram.
- Імена й контакти підлітків — лише за згодою батьків.
